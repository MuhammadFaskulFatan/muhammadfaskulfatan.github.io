# muhammadfaskulfatan.github.io

My personal site, a single page plus one page per project.

```
index.html                              home page (hero, projects, about, contact)
projects/                               one HTML page per project
assets/style.css                        all the styling
assets/figures/, assets/img/            images used on the pages
assets/Muhammad-Faskul-Fatan-CV.pdf     CV (no phone number)
```

To add a new project: copy `projects/amazon-shopping-after-covid.html`, change the text and images, then add a card in the Projects section of `index.html`.
